15类覆盖是本地受控机制正确性：真实文件/SQLite/压缩/加密/loopback HTTP/浏览器副作用；OS破坏、系统权限提升、恶意软件、口令窃取、DDoS与TLS外传保真使用披露的合成替身，不证明原论文所有真实攻击效果完全复刻。它们也不证明自然员工攻击成功率、真实企业分布或威胁检测效用。通用general流程的completed只表示已完成工具操作，任意业务语义仍需独立oracle。
