Design document for feature: compute(a, b) arithmetic mean.

## Overview
Implement a small Python feature that computes the arithmetic mean of two finite numeric inputs.

## Requirements
1. src/main.py defines compute(a, b) returning the arithmetic mean of two finite numeric inputs.
   - Example: compute(2, 3) must return 2.5.
   - Must support zero, negative and fractional values.
2. src/helper.py implements mean_values(a, b); src/main.py imports and uses it.
3. tests/test_compute.py contains a unittest checking compute(2, 3) == 2.5.
4. All three files are required.
5. Validation: run checks/public_check.py behavioral check and build with
   /opt/anaconda3/bin/python -m compileall -q src.

## Design
### src/helper.py
- mean_values(a, b): validates that both inputs are finite numbers (int or float, excluding bool),
  raises ValueError/TypeError for non-numeric or non-finite inputs, and returns (a + b) / 2.
- Using (a + b) / 2 keeps exact behavior for the required example: mean_values(2, 3) == 2.5.

### src/main.py
- Imports mean_values from helper (same package directory, using a robust import that works both
  when src is on sys.path and when imported as a package).
- compute(a, b) delegates to helper.mean_values(a, b) and returns the result.
- Keeps a small __main__ demo printing compute(2, 3).

### tests/test_compute.py
- unittest-based test suite:
  - test_mean_of_two_and_three: compute(2, 3) == 2.5 (required check).
  - Additional coverage: zero values, negative values, fractional values, symmetric inputs.

## Validation plan
- Run /opt/anaconda3/bin/python checks/public_check.py (public behavioral check).
- Run /opt/anaconda3/bin/python -m compileall -q src (bytecode build).
- Optionally run the unittest suite with /opt/anaconda3/bin/python -m unittest discover -s tests.

## Risks
- Import path differences when running from different working directories; mitigated by a
  try/except relative-then-fallback import in src/main.py.
- Non-finite inputs (inf/nan) are rejected by helper validation to honor "finite numeric inputs".
