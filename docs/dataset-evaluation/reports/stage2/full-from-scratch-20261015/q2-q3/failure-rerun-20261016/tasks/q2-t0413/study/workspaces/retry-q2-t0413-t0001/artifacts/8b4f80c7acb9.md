Design Document: Arithmetic Mean Feature (compute / mean_values)

1. Overview
Implement a small Python feature that computes the arithmetic mean of two finite numeric inputs. The public entry point is compute(a, b) in src/main.py, which must return the arithmetic mean, e.g. compute(2, 3) == 2.5. The core math lives in mean_values(a, b) in src/helper.py, and src/main.py imports and uses it. A unittest in tests/test_compute.py verifies the required behavior.

2. Requirements
- R1: compute(a, b) defined in src/main.py returns the arithmetic mean of two finite numeric inputs.
- R2: compute(2, 3) must return 2.5.
- R3: Zero, negative and fractional values must be supported (e.g. compute(-2, 2) == 0.0, compute(0.5, 0.25) == 0.375).
- R4: mean_values(a, b) implemented in src/helper.py; src/main.py imports and uses it (no duplicated math in main).
- R5: tests/test_compute.py contains a unittest checking compute(2, 3) == 2.5.
- R6: All three files required: src/main.py, src/helper.py, tests/test_compute.py.
- R7: Validation: run checks/public_check.py with /opt/anaconda3/bin/python and build with /opt/anaconda3/bin/python -m compileall -q src.

3. Design
3.1 src/helper.py
- Define mean_values(a, b):
  - Validate that both a and b are numeric (int or float, excluding bool) and finite (math.isfinite). Raise TypeError for non-numeric inputs and ValueError for non-finite values (NaN, +/-inf).
  - Return (a + b) / 2 as a float. Using float() conversion guarantees fractional results (2.5 for compute(2, 3)) even for int inputs.
- No side effects; pure function.

3.2 src/main.py
- Import mean_values from helper. To make the import robust both when run as a module and when src is on sys.path (as checks/tests typically do), use a try/except import: first try a relative-style package import (from .helper import mean_values), falling back to a direct import (from helper import mean_values) when src is the working directory / on sys.path.
- Define compute(a, b) as a thin delegation: return mean_values(a, b). This satisfies R4 (main uses the helper) and keeps a single source of truth for the math.
- Expose __all__ = ["compute"].
- No top-level executable behavior required; keep the module import-safe.

3.3 tests/test_compute.py
- Use unittest. Import compute from src.main by inserting the workspace root into sys.path (os.path + sys.path manipulation relative to the test file location) so the test runs with plain `python -m unittest` or pytest from the workspace root.
- Test cases:
  - test_basic: compute(2, 3) == 2.5 (required by R5).
  - test_zero: compute(0, 0) == 0.0 and compute(-4, 4) == 0.0 (zero support).
  - test_negative: compute(-2, -4) == -3.0 (negative support).
  - test_fractional: compute(0.5, 0.25) == 0.375 (fractional support).
  - test_returns_float: result is a float instance.
- Guard against accidental non-finite inputs in tests is not needed; tests only use finite values.

4. Data flow
compute(a, b) [src/main.py] -> mean_values(a, b) [src/helper.py] -> validated, finite-checked -> (a + b) / 2 -> float result returned to caller.

5. Error handling
- Non-numeric input (str, None, list, bool): TypeError from mean_values.
- Non-finite numeric input (float('nan'), float('inf')): ValueError from mean_values.
- compute propagates these errors unchanged; no silent coercion.

6. Validation plan
- Phase test_run: run the public behavioral check /opt/anaconda3/bin/python checks/public_check.py (must pass).
- Phase build: /opt/anaconda3/bin/python -m compileall -q src (bytecode compilation of src must succeed).
- Local simulated review and approval phases afterwards.

7. Out of scope
- Means of more than two values, weighted means, statistics module usage, packaging (build/pip), and any CLI entry point.
