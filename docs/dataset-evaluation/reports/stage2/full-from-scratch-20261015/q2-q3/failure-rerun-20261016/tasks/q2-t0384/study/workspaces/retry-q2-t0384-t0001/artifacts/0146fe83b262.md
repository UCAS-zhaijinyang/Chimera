Design document for compute(a, b) feature.

## Overview
Implement a public function `compute(a, b)` in `src/main.py` that returns the maximum of two finite numeric inputs.

## Requirements
- `compute(2, 3)` must return `3`.
- Support zero, negative, and fractional values (e.g., `compute(-1, 0)` -> `0`, `compute(2.5, 2.4)` -> `2.5`, `compute(-3.5, -2.5)` -> `-2.5`).
- Inputs must be finite numeric values (int or float, including bool as int subclass is acceptable but not required to special-case).
- Non-numeric or non-finite inputs (NaN, infinity, strings, None) are outside the supported domain; behavior for them is unspecified but a defensive TypeError/ValueError may be raised.

## Design
- Location: `src/main.py`, module-level function `compute(a, b)`.
- Implementation: validate that both arguments are real numbers (`numbers.Real`) and finite (`math.isfinite`), then return the larger of the two using a simple comparison (`b if b > a else a`) to avoid relying on built-in `max` semantics and to preserve the original numeric type of the winning argument.
- No external dependencies; standard library only.

## Validation
- Public behavioral check: `/opt/anaconda3/bin/python checks/public_check.py`.
- Build: `/opt/anaconda3/bin/python -m compileall -q src`.

## Risks
- None significant; pure function with no side effects.
