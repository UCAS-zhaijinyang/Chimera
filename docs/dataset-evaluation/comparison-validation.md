# 原始 Chimera 与当前框架：数据质量 → 检测效用

状态：**待执行比较协议，没有第二/第三阶段实测结果。** 本版按用户确认的主线重构：**原始 Chimera 与当前框架的数据质量对比 → 使用相同检测方法验证检测效用差异。** 第一阶段实测报告保持原样。

## 1. 主对照是谁

| ID | 来源 | 必须记录 | 可以怎样解释 |
|---|---|---|---|
| O | 原始Chimera发布的数据快照，或固定原版代码生成的数据 | 来源/许可、数据hash；复现时额外记录原仓库commit、模型、场景、参数及环境 | 发布快照的比较或原版复现，分别命名 |
| N | 当前框架新生成的确认数据 | 本分支冻结commit、DeepSeek实际型号/usage、相同高层业务规格、run与数据hash | 当前完整框架的数据质量与检测用途 |

O不是“当前框架关闭workflow开关”。第一阶段旧失败队列和round24原描述重放也不是原始Chimera数据。master/dev的名称不能替代原版来源审核。当前原始来源尚未登记核验，登记模板见[比较manifest](comparison-manifest.template.json)。

有原始快照时不重复付费生成；缺少快照时才适配固定原版代码，以相同可用DeepSeek型号和高层业务条件复现。只做输入/模型API兼容与只读采集适配，不把当前router、工具行为或规划机制移植进原版。偏离论文模型或配置必须记录，不称完全复现论文分数。

双方按共同高层任务、场景、角色、人数、时长、可观察模态和样本量设计比较；完整框架各自保留其机制，不冻结成同一当前规划器。模型或规模无法匹配的已有快照作数据集比较，混杂条件逐项公开，不把差异全部归因某一个组件。

规则/模板、单轮DeepSeek、CTGAN/时序生成器及当前legacy开关均为**可选补充或消融**，不再是主比较的必做来源，不占默认样本、人工或API预算。

## 2. 两个阶段的任务边界

| 阶段 | 输入 | 主要问题 | 主表 |
|---|---|---|---|
| 第二阶段 | O/N原始记录、共同业务上下文、可观察成果与参考 | 当前数据在业务、结构、覆盖与语义上有哪些改善或退化？ | 指标×原版/当前版/差值/95%CI/能力范围 |
| 第三阶段 | 同一批O/N的训练分割、冻结检测器、共同独立target | 换训练数据后，相同检测方法的效果是否改善？ | 检测器×O训练/N训练/同一target/差值/95%CI |

新增数据只生成一次，两阶段复用。原始数据、失败、拒绝和unknown不可删；每份新数据重新验收L0。缺证据不记正常，也不记业务失败；能力不支持用NOT_APPLICABLE，能力要求但缺观测用NOT_MEASURED，并报告可评价比例。

## 3. 第二阶段：按共同证据比较质量

| 任务 | 主要指标 | 横向比较条件 |
|---|---|---|
| Q1 计划落实 | 匹配P/R/F1、到期目标完成率、阶段偏差 | 两源都有明确计划/稳定映射与成果判据；否则只比可观察子集 |
| Q2 成果与稳定性 | 独立业务成功率、pass^1/pass^3、禁止副作用率 | 两源共享任务规格、可执行成果和初始环境；无产物的O不能被填0或判输 |
| Q3 跨人/跨天连续性 | 正确handoff、版本/ACL、跨天依赖完成率 | 两源都有实际生产与消费证据；会议名单和模拟收件人不能替代消费 |
| Q4 分布、节奏与多样性 | KS/Wasserstein/TV、ACF误差、覆盖、重复、图结构 | 固定共同字段/语义、时间与观察量；有共同外部R时都对R比较 |
| Q5 模拟攻击语义 | 可评价episode覆盖、动作链、严重语义缺陷、成功/阻断/未知 | 固定攻击语义映射与证据等级；不把意图当执行 |
| Q6 独立盲评与judge验证 | 四维评分/缺陷率、α、MAE/κ、缺陷召回、abstain | 隐藏来源，主比较用共同证据与相同量表；缺必要证据不能猜 |

Q7不是再造一组数据：它汇总Q1–Q6的O/N配对差异、成本与局限。比较共同日志质量与当前特有能力分表。N新增血缘/产物能力可作为能力增量，但不能借丰富上下文在共同日志评分中取得不公平优势。

同一外部R上报告D(O,R)、D(N,R)及差值。没有R时D(O,N)只表示两源不同，不能把“更接近原版”或“更不同”自动解释为更真实。

### 人工样本与主要统计

起步60校准包＋180独立确认包，每包3专家；确认为3共同场景×O/N两源×30包，每cell正常/攻击诊断各15。适配失败、少数角色和unknown按冻结抽样规则保留。没有对应场景或攻击样本则缺格/缩窄比较，不从其他格偷补。每包四维，但实际缺成果证据的维度abstain；共同维度逐项比较，可核验成果维度只有双方都有证据时进入主对比。

同厂DeepSeek只辅助评分，60挑战包、60必要复评、60Pro升级作为预算起点。原四源120额外确认包不再默认执行，也不并入O/N确认主表。独立评分按3分钟约36人小时，6分钟约72小时，准备与仲裁另计。

主质量指标预注册共同证据下的业务内容盲评分差值及严重语义缺陷率差值；若两源都支持相同独立oracle，业务成功率差值另列主指标并处理多重检验，否则它是受限范围/当前专项结果。α衡量评分可靠性，不是数据质量总分。

严重语义缺陷率定义为：至少含一项独立确认严重缺陷的可评价证据包数／全部可评价证据包数，取值0–1。严重性标准、taxonomy和证据要求在确认前冻结；同包同一事件/类型的重复标注去重，多项缺陷也只计一个有缺陷包。3位专家先独立判断，同一证据缺陷至少2人确认且至少2人认为包可评价才进入确认；其余争议交盲化仲裁，未解决记abstain/UNKNOWN。证据不足不能记无缺陷，单列可评价coverage、abstain及分来源原因，主比较限定共同可评价范围。缺陷数量另报“每100可评价包缺陷数”，不混入主比例；原始判断、仲裁与去重记录均保留。

## 4. 第三阶段：检测方法相同，只更换训练源

原论文明确使用**RBF-SVM、Temporal CNN、GCN、DS-IID**，见[名称与架构核验](evidence/original-chimera-detectors.json)。主比较保留这四种既有方法。实现尚未获取/冻结；不得因CPU成本方便而把主方法改成logistic regression或树模型。轻量模型可免费调试特征/标签流程，不能替代缺失的四方法主结果。

每个方法都有同一份代码版本、架构、特征语义、预处理规则、时间/图构造、搜索空间、epoch/early-stop规则与seed清单：

```text
O_train → 检测器M的一个训练实例 → 冻结共同target
N_train → 同一检测器M的另一训练实例 → 同一个target
```

两实例分别从头训练，不要求权重相同。主比较匹配训练正常单位数与攻击episode数、任务/标签口径和调参机会；不同规模/总成本曲线另列。匹配采样只用train/validation，target保持原阳性率。

默认双方用同一个冻结的源内公共验证池V_common，来自O/N的验证组，获得相同调参/阈值信息。缺共同验证条件时，在确认前声明对称的source-only验证协议并另命名；外部target标签不可调参，使用外部验证集的实验必须标目标适配，不冒充零适配转移。

### 共同测试集的优先级

1. 有许可、标签与共同模态充分的独立外部holdout时，先导后冻结一个主target；O训练和N训练都测试它。
2. 暂无合格外部target时，冻结O_test与N_test的共同测试池T_common。两模型均评价两个域，分域结果及预注册50/50域宏平均全部报告；域内保留原阳性率。这只支持内部合成持有比较。
3. 有未见场景/攻击族/新模板时，两训练源均评价同一个相应holdout；只能对已取得的持有条件声称泛化。

测试run/员工协作组/episode/模板族与训练、验证隔离，时间窗口和跨组桥接审计。样本重复/近重复检查避免泄漏；不把同一攻击的数百事件当数百独立攻击。公共快照没有run字段时用其真实独立群体，不伪造run ID。

### 主方法的输入要求

RBF-SVM用共同用户日特征；Temporal CNN用合法过去窗口，边界不跨split；GCN按共同可验证关系构图，测试标签/未来边不可传播进训练；DS-IID按原实现的序列、重构与分类训练要求冻结。输入缺失时先适配或明确未测，不为凑四方法伪造图或时间。原架构一致，不要求不同架构之间特征表示完全相同；同一个方法的O/N比较必须一致。

## 5. 检测实验矩阵

| ID | 必做或可选 | 实验 | 固定什么 |
|---|---|---|---|
| D0 | 必做冻结 | O/N来源、字段/标签、split、target、四检测器 | 代码/config/hash、共同验证及seed/汇总规则 |
| D1 | 主实验 | 四方法各比较O_train与N_train | 同方法、共同特征、相同训练量/调参预算、同一target |
| D2 | 必做运营评价 | episode召回、正常误报与日终延迟 | 同报警预算/观察范围，未检出按删失 |
| D3 | 必做审计 | 标签/路径/模板泄漏与随机训练标签负控制 | target真值不变，所有处理在train/validation制定 |
| D4 | 有数据即做 | 外部直接转移、未见场景/攻击族/模板 | 两训练源同一外部或未见条件target |
| D5 | 次级 | 当前数据加血缘/图或缺模态/时间噪声 | 同holdout，额外字段的价值单列，不混入共同字段主效果 |
| X1 | 可选 | 外部R_only、R+duplicate、R+O、R+N增强 | 同R_test，同合成增量与正常/阳性数，排除只增加行数 |
| X2 | 可选 | legacy开关、规则/单轮、统计生成器、规划消融 | 新manifest和独立预算，不改主O/N对照 |

主指标ΔAP与ΔRecall@固定审查预算；辅助报Precision/Recall/F1/ROC-AUC/MCC、FPR/千正常员工日、episode召回与延迟。阈值只用验证集选，AP用连续分数，测试不重平衡。未检出延迟按删失并报数量，日终评分只能报告日终延迟。

## 6. 统计、判定与适用范围

质量按独立run/场景/任务组重采；共同target上的两预测使用同一重采索引，按实际独立测试组/episode算差值95%CI。配对生成只有真实同条件run对应时才用配对分析；已有不可配对快照使用分组独立两样本CI，并解释混杂。

确认前冻结同一组配对训练seed（候选5个）及每seed的验证阈值选择规则。每seed分别算O训练、N训练的指标和差值，主表用全部预定seed的指标算术均值及平均差值，同时保留逐seed结果、标准差和范围；不得挑最优seed或平均预测分数后暗中作为集成模型。内部双域先按每seed计算各域指标，再用固定50/50权重宏平均，最后平均seed。主95%CI条件化于这组冻结已训练模型：每次bootstrap对所有seed和两训练源使用同一target组/episode重采索引，重算逐seed指标再平均，seed不在主bootstrap中重采；训练seed变异另表，训练数据生成不确定性另做外层训练组重采并重训。确定性方法可复用经核验完全相同的拟合，记录重复对应，不把重复结果当额外独立样本。预定seed运行失败必须报告并重跑；未补齐不得选择性删除后填完整主结果。

训练seed不等于生成run，测试bootstrap不包含训练数据生成不确定性。需后者时另做训练组重采样并重新训练，单列compute。参考少、两测试run或少阳性时报告宽区间/INCONCLUSIVE，不用大量日志行虚增样本量。

硬规则零违规；质量/非劣/实用优势界限在先导后、确认前冻结。p>0.05不证明等价，单个检测器提升不证明全面提升。固定主方法与主target，必要的多重比较按预注册Holm控制，完整报告退化和最差组，不挑最好模型作唯一结论。

CERT是外部合成参照，TWOS是人类竞赛参照，授权企业heldout才支持企业TSTR。内部T_common不称外部有效。原始缺少成果只能限定成果比较，不能用检测高分补成业务正确。
