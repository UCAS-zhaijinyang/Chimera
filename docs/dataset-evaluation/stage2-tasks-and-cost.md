# 第二阶段：行为与成果合理性——详细任务与成本

状态：**分析与预算设计，尚未执行第二阶段实验。** 更新：2026-10-13。第一阶段结论见[总报告](reports/stage1/README.md)。本文件把既有L1–L4方案改写成按测试目的阅读的任务说明，数值预算见[可复算成本表](stage2-cost-estimate.json)。

**第二阶段的目的：检查生成的数据在更丰富的业务、角色、多日和模拟攻击条件下，是否有合理的任务成果、行为结构与语义，并比较它相对其他生成方法的表现。** 第一阶段已证明指定简单任务的执行与记录正确；第二阶段扩展任务范围、时间跨度和比较对象。威胁检测的AP、召回、误报及数据增强效用留第三阶段。

## 1. 哪些证据能复用，哪些需要新增

| 已有证据 | 第二阶段怎么用 | 不能直接推出什么 |
|---|---|---|
| 54个明确规格任务的独立业务验收 | 复用检查器与fixture作为工程回归，作为生成成本参考 | 不能代表复杂业务或真实企业总体成功率 |
| 27个受控异常与9个模拟攻击目标 | 复用边界处理、记录/标签检查 | 不能代表自然攻击分布或攻击语义真实性 |

新证据应包含更丰富的明确业务规格、不同角色、多日计划和任务依赖、不同独立run、独立生成基线，以及随机人工盲评。原描述队列缺少业务oracle，仍只复用其执行可靠性证据与费用参考。

**当前必须处理的前置项：** 现有评测runner的simulation_time是任务起点加事件序号毫秒，不能代表真实员工耗时与工作节奏；跨任务共享在能力位中仍为false。必须补充可验证的计划/业务时间与跨任务产物消费证据，才能验收下述节奏、交接和跨天连续性。只有逻辑序号时只报告顺序正确，不给真实性结论。旧路径也需要同口径执行/采集adapter，缺失能力不记满分或强行比较。

## 2. 任务A：检查计划与实际工作是否一致

**要证明什么：** 员工行为围绕分配的业务目标展开，任务与阶段/期限对应，额外行为有明确解释。

**详细检查：**

- 用稳定activity/goal ID把每个计划工作单元匹配到实际执行任务；一次活动的多次工具调用只算一个工作单元。
- 对所有到期目标检查实际业务成果，而不是只核对任务名称或completed标签。
- 统计遗漏目标、做错阶段、提前/延迟及计划外行为；正式变更与无解释行为分开。
- 正常业务与模拟攻击分别解释；预定攻击行为不能机械地当成正常计划失真。

**指标/判定：** 工作单元匹配P/R/F1、目标完成率、阶段/期限偏差、计划外行为组成；明确硬阶段约束违规为0，延期按业务类型统计。正式软门槛在先导后冻结，不能预设所有业务零延迟。

**成本：新增检查API $0。** 使用下文共用数据；业务计划生成费用计入共享采集账本，当前尚未实测。开发映射/业务规格和人工复核时间另记。

## 3. 任务B：检查更丰富的业务成果与副作用

**要证明什么：** 通过第一阶段的简单函数与汇总后，框架面对更丰富输入和业务约束仍产生可核验成果。

**详细检查：**

- 报告：多字段、筛选与分组等确定性需求，输入改变后成果随之改变；文件、副本与交付对象符合规格。
- 开发：增加多文件、依赖与不同输入；独立功能测试，并检查测试/构建证据对应最终代码版本。
- 修复：实际修改前失败、修改后通过，另检查预定旁路用例，防止修一处坏一处。
- 对每个任务检查允许写入范围和前后文件变化，未授权修改、其他任务文件受损不能被“任务完成”掩盖。
- 从相同初始快照独立运行，报告一次成功率与三次都成功的比例；保存所有失败和最差角色/流程。

新增需求必须有事先固定、独立审核的oracle；不拿开放式业务文本直接声称“结果全部正确”。旧路径不具备真实成果时，只报告其可观察范围。

**指标/判定：** 完整业务成功率、检查点完成率、内容—交付链正确率、禁止副作用、pass^1/pass^3。受控黄金规格要求全部通过；更广确认数据报告成功率、分层结果及对照差异/区间，阈值先导后冻结。

**成本：检查API $0；新增任务生成已包含共享数据预算。** 第一阶段workflow黄金队列可复用作工程回归，不重复生成收费。若补同口径旧路径90黄金任务，费用尚未实测；按新路径单任务费暂作占位约$0.63–$0.97（含20%），不能当旧路径正式报价。

## 4. 任务C：检查跨人交接和跨天连续性

**要证明什么：** 任务形成可执行协作链，后续任务确实使用前序成果。

**示例：** A第一天生成报告v1，B第二天必须读取v1并完成审核；第三天新任务要求使用更新后的v2。检查读取的实际版本、消费者身份、访问权限和最终内容。

**详细检查：** 生产先于消费；交接给正确对象；接收者实际能读；消费版本正确；前日成果确实影响后续输出；缺少输入时不能凭空声称交接完成；禁止只把邮件收件人或会议名单当成实际协作边。

**指标/判定：** handoff正确率、接收者可读率、跨天依赖完成率、遗忘/重复生产率、协作图覆盖。受控必需交接全部正确，硬因果/身份错误为0。没有跨任务索引或消费事件则NOT_MEASURED。

**成本：检查API $0；多日生成共用同一数据。** 实现共享索引/ACL适配、编写交接fixture是工程工作量，尚无工时报价。

## 5. 任务D：检查工作节奏、角色分布和多样性

**要证明什么：** 数据集有合理覆盖和结构，生成结果不只是少数模板反复复制。

**详细检查：**

- 角色×部门×阶段×工作流覆盖、任务数与失败数；必需单元是否缺失。
- 每日工作量、行为类别比例、工作时段、任务间隔、跨日关联与状态转移；只能使用有业务含义的时间证据。
- 员工/部门之间实际消息及产物消费图，是否符合任务指定协作关系。
- 去除ID、路径和时间标识后的完全/近重复、最大重复簇；例行固定文本单列。
- 同配置不同run的波动与最差run；不能挑最好的一次作为整体结果。
- 有外部参考时，对共同字段按角色/场景比较分布距离；没有外部参考时只报告内部规格一致性与基线差异。

**指标/判定：** 必需覆盖率100%；其余使用条件分布距离、时间结构、重复率、协作图及run差异。距离阈值按参考自身波动在先导阶段校准，不统一强设KS≤0.10，也不因生成源难区分就宣布真实。

**成本：本地统计API $0。** 本机CPU/存储计实际占用；使用现有机器时不一定有新增现金费用。云机器、参考数据获取/许可及字段适配单列，当前未知。

## 6. 任务E：检查模拟攻击行为的业务语义是否合理

**要证明什么：** 在记录和标签正确的基础上，模拟攻击有可解释的角色、访问条件、目标与动作链。

先导候选至少三族：模拟外发、指定对象越权修改、模拟审批/授权滥用。先检查是否能在当前隔离工具环境执行并留下证据，不能为凑攻击族伪造成功或放开隔离范围。不可执行族改报被阻止尝试或能力缺失。

**详细检查：** 角色能否接触目标；动作是否足以影响指定对象；成功/阻断/未执行是否有证据；正常与异常差异是否可观察；被阻断行为和失败保留；任务指定影响范围外的破坏不被“这是攻击”豁免。

**指标/判定：** 实际攻击episode覆盖、可解释动作链、证据充分率、攻击相关语义缺陷、成功/阻断/未知组成。硬证据问题为0；语义判断进入下文共同盲评，不另为每条攻击重复收费。公开的第一阶段9目标不替代新族证据。

**成本：自动证据检查API $0；攻击任务生成已包含共享数据；语义评分包含任务F。** 攻击规格撰写及真值人工审核单列，工时尚未知。这项不运行检测器，不计算检测召回。

## 7. 任务F：独立人工盲评，并校准DeepSeek辅助评分

**要证明什么：** 数字检查之外，业务内容、角色能力、时间协作和成果解释有合理语义；DeepSeek评审能发现已知缺陷，且偏差受检查。

每包同时评价四个维度：业务内容可信、角色/能力一致、时间/协作可信、成果可核验，各1–5分或证据不足abstain。证据包隐藏生成方法和真标签，保留判断所需角色、任务、权限及实际失败证据；不能按模型高分选人工样本。

| 子任务 | 规模与方法 | 含20%预留的API估算 | 三专家评分工时，3分钟/次 |
|---|---|---:|---:|
| 校准量表与提示 | 60包，由人工先独立评分，与Flash比较 | $0.11664 | 9人小时 |
| 冻结后的主确认 | 180包，覆盖3场景×新旧2条件，失败与少数角色保留 | $0.34992 | 27人小时 |
| 评审器语义挑战 | 60包，含已知错误/正常对照、错误交接、虚构成果、提示注入等 | $0.11664 | 挑战真值编写/审核另计，不是0人工成本 |
| 必要重复评审 | 预留60次Flash，仅检查稳定性/修复无效格式 | $0.11664 | 不替代独立人工 |
| 疑难升级 | 预留60次Pro，同一证据重新评审 | $0.456192 | 不算额外独立专家 |
| 独立生成方法共同日志确认 | 120包，3场景×4生成源×10包，与任务G共享 | $0.23328 | 18人小时 |
| 合计 | 480次Flash＋60次Pro＝540次调用 | **$1.389312，约$1.39** | **54人小时** |

价格假设每次3,000输入＋600输出token、峰价无缓存、非thinking。长证据、更多升级/重试需更新账本，20%是预留而不是最高价。必要上下文不能为满足短包预算删掉。挑战真值审核、证据打包、培训、招募和仲裁未计入54小时；复杂包若每次6分钟，独立评分为108人小时。

**指标/判定：** 四维分数/分布/区间、严重语义缺陷率、abstain、人工一致性α、模型—人工误差和缺陷漏判。候选α≥0.80较可靠；0.67–0.80暂定，更低需修量表/报告不确定。模型候选MAE≤0.5、严重缺陷召回点估计≥0.90且95%下界≥0.80，均须先导冻结且样本量支持；不足则INCONCLUSIVE。模型不合格仍保留人工主表，不能用同厂模型多数投票替代真人。

## 8. 任务G：与其他生成方法比较，并寻求外部印证

**要证明什么：** 当前框架的合理性证据不只来自自身检查，而且比较能说明机制带来的差异。

比较四个来源：旧执行路径、当前workflow、独立规则/模板、单轮DeepSeek文本生成。统一业务规格、角色与可观察共同字段，主比较匹配样本量；模型档位/参数一致。新旧路径复用相同规划快照，仅将差异归因执行机制；规划2×2消融另列为可选增量。

- 比较覆盖、重复、正常行为分布、时间/关系结构及共同日志人工评分。
- 完整轨迹成果只在实际提供执行与产物证据的来源之间比较；规则/单轮文本没有执行文件时，不计算虚构业务成功率。
- CERT可用于外部合成参照；取得许可与文件后的TWOS可用于人类竞赛参照；授权企业日志才可支持企业真实性参照。参考来源分别命名，未取得时保留未测。
- 外部参考的校准与确认分离；确认/第三阶段测试数据不用于调生成器、规则或judge。

**指标/判定：** 共同字段距离、最差组覆盖、独立盲评分差异及置信区间；业务oracle按能力适用。非劣界限或实用优势在先导后冻结，不能仅因为比旧路径高就声称像真实企业。

**成本：** 规则/模板生成API $0；单轮DeepSeek新增先导360员工日及训练/验证确认2,880员工日，每员工日一次4,000输入＋1,000输出请求，含20%合计**$9.3312**。其中先导$1.0368，确认$8.2944。旧路径生成见共享预算，人工比较的$0.23328/18小时已在任务F计入，不再相加。基线适配、规则开发与外部数据获取另记工时/费用。CTGAN/时序生成器、规划消融暂作可选，不纳入主预算。

## 10. 推荐执行顺序与交付

1. 复用L0和第一阶段oracle，构建业务/角色/攻击规格，审核当前时间、跨任务共享和旧路径适配能力；先不发付费调用。
2. 免费验证扩展oracle与语义挑战真值，然后只跑先导和人工校准，保留全部失败；测出分路径、规划与长链实际费用。
3. 根据先导冻结确认数据规模、参考、指标、差异界限、抽样和预算，校准/确认按run和模板隔离。
4. 生成不可变确认数据，各任务本地全量检查，随机人工盲评并计算对比及区间。
5. 每任务输出详细报告：输入/hash、分母、检查方法、数值/区间、失败实例、证据路径、未测项和实际API/人工账本。修复后新建确认版本，旧失败报告与数据继续保留。
